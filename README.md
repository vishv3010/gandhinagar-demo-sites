# Local Business Demo Websites — Gandhinagar

Free demo websites built for local Gandhinagar businesses that don't have one yet, as
a pitch to get them online (and as paid work for the person contacting them).

Each folder under `sites/` is a fully self-contained, static one-page site
(no build step, no dependencies beyond Google Fonts) — just open `index.html`
in a browser, or serve the folder as-is.

## Before sending any of these to a business owner

- Set the real `PHONE` value near the bottom of each site's `<script>` tag
  (enables the Call / WhatsApp buttons).
- Swap the placeholder watermark ("GN Webcraft — Vishv Patel") for your real name/brand + contact.
- Confirm menu/service prices in person — the price notes on each site are clearly
  labeled indicative estimates, not confirmed numbers.
- Gallery photos are representative stock, labeled as such — swap in the business's
  own photos once they're on board.
